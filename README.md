## Железо: 6 ноутов
- **1 Ubuntu = vulnbox** (сервак): на нём крутятся НАШИ сервисы. Его защищаем. Заходим на него по SSH.
- **5 Kali** = рабочие машины (по одной на человека): с них атакуем других и анализируем трафик.
- **Докера нет** — всё локально (процессы/systemd, файлы, локальные БД).

## Факты про флаги (ForcAD)
- Формат флага: `[A-Z0-9]{31}=` (32 символа, кончается `=`) — уточнить.
- Флаг живёт **5 раундов (~10 мин)**, раунд ~2 мин.
- **По 2 флага на уязвимость** в сервис за раунд.
- attack_data (цели): `http://<host>/api/client/attack_data` — уточнить адрес на /serp.
- Сабмит флагов: по TCP (`forcad_tcp`, host:port) — в ферме.

## 5 золотых правил
1. Главное — **не лежать и не отдавать флаги**. Упавший сервис (красный SLA) — минус очки.
2. **tcpdump с 10:00** — воруем чужие эксплойты из дампа, это наш главный источник атаки.
3. **Бэкап всего ДО открытия сети** (железо физическое, отката нет).
4. **Патч, не блокировка** — чекер ходит с того же диапазона, бан убьёт SLA.
5. **Всё говорим вслух**: нашёл баг / патчу X / ферма сдаёт.
